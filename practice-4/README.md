Уровень B. Откройте `practice_4.ipynb`, установите зависимости из `requirements.txt` и выполните Run All.

## Описание результата

Во всех работах используется IBM Telco Customer Churn: 7043 клиентов и 21 признаков. Целевая переменная `Churn` показывает, ушёл ли клиент. В данных есть пропуски в `TotalCharges` и дисбаланс классов, поэтому графики и метрики нужно интерпретировать с учётом этих особенностей.

### Регрессия

Ridge оценивает TotalCharges по сроку обслуживания и ежемесячному платежу. MAE показывает среднюю ошибку, RMSE сильнее учитывает большие ошибки, R² — объяснённую долю вариации. Вывод: график факт/прогноз показывает качество базовой модели.

Откройте `practice_4.ipynb` и выполните **Run All**: график и таблица результата находятся внутри notebook.
