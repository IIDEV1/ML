# Практическая работа №3. Подготовка данных и pipeline

## Цель

Подготовить таблицу к машинному обучению воспроизводимым способом. Главная задача — превратить смешанные числовые и категориальные столбцы в матрицу признаков, которую принимает алгоритм.

## Исходные данные

Работа выполнена на IBM Telco Customer Churn: 7043 наблюдения, целевой столбец `Churn`. В таблице одновременно присутствуют числа (`tenure`, `MonthlyCharges`, `TotalCharges`) и текстовые категории (тип договора, интернет-сервис, способ оплаты и другие поля).

## Этапы подготовки

1. `customerID` исключён, потому что это уникальный идентификатор, а не характеристика поведения клиента.
2. `TotalCharges` приведён к числовому типу, некорректные пустые значения заменяются медианой внутри pipeline.
3. Числовые признаки проходят `SimpleImputer` и `StandardScaler`.
4. Категориальные признаки проходят заполнение наиболее частым значением и `OneHotEncoder`.
5. Для объединения этапов используется `ColumnTransformer`.
6. После разделения на train и test pipeline обучается только на train-части.

## Почему это важно

Если сначала посчитать статистики по всей таблице, информация из тестовой части попадёт в обучение. Это называется утечкой данных и делает оценку модели слишком оптимистичной. Pipeline хранит все операции в одном объекте и применяет к тесту те же правила, которые были получены на train.

## Результат

После кодирования категорий число признаков увеличивается, потому что каждая категория превращается в отдельный бинарный столбец. На выходе получается числовая матрица, пригодная для классификаторов из scikit-learn. В notebook показаны размеры исходных и подготовленных train/test данных.

## Вывод

Предобработка завершена в едином воспроизводимом pipeline. Этот pipeline можно передавать разным моделям и сравнивать их на одинаковых данных. Такой подход снижает риск ошибок и является основой следующих практик.
