# Практическая работа №7. Случайный лес

Уровень B. Откройте `practice_7.ipynb`, установите зависимости из `requirements.txt` и выполните Run All.

## Описание результата

Во всех работах используется IBM Telco Customer Churn: 7043 клиентов и 21 признаков. Целевая переменная `Churn` показывает, ушёл ли клиент. В данных есть пропуски в `TotalCharges` и дисбаланс классов, поэтому графики и метрики нужно интерпретировать с учётом этих особенностей.

### Случайный лес

Случайный лес сравнивается с базовой моделью на одной тестовой выборке. Важность признаков показывает вклад характеристик в прогноз, но не доказывает причинность. Вывод: модель подходит как сильная базовая модель для Telco Churn.

Откройте `practice_7.ipynb` и выполните **Run All**: график и таблица результата находятся внутри notebook.
