# Практическая работа №1. Настройка окружения и первый notebook

Уровень B. Откройте `practice_1.ipynb`, установите зависимости из `requirements.txt` и выполните Run All.

## Описание результата

Во всех работах используется IBM Telco Customer Churn: 7043 клиентов и 21 признаков. Целевая переменная `Churn` показывает, ушёл ли клиент. В данных есть пропуски в `TotalCharges` и дисбаланс классов, поэтому графики и метрики нужно интерпретировать с учётом этих особенностей.

### Первичный анализ

Проверяются размер таблицы, типы столбцов, пропуски и базовые статистики. Графики показывают баланс Churn и распределение MonthlyCharges. Вывод: перед моделированием нужно обработать TotalCharges, учитывать дисбаланс классов и закодировать категории.

Откройте `practice_1.ipynb` и выполните **Run All**: график и таблица результата находятся внутри notebook.
