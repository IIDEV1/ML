# Практическая работа №1. Первичный анализ данных

## Цель

Познакомиться с датасетом телеком-компании и понять, какие данные можно использовать для прогноза оттока клиентов. На этом этапе модель ещё не строится: сначала проверяется качество исходной таблицы и формулируется задача.

## Исходные данные

Используется IBM Telco Customer Churn. В таблице 7043 строки и 21 столбец. Одна строка соответствует одному клиенту. Есть идентификатор клиента, срок обслуживания `tenure`, ежемесячный платёж `MonthlyCharges`, общая сумма платежей `TotalCharges`, параметры договора, подключённые услуги и способ оплаты.

Целевая переменная — `Churn`: значение `Yes` означает, что клиент ушёл, а `No` — что клиент остался. Это бинарная задача классификации.

## Что выполнено

1. Файл CSV прочитан в `pandas.DataFrame`.
2. Проверены размер таблицы, названия и типы столбцов.
3. Найдены пропуски и проверено наличие дубликатов.
4. Числовые признаки преобразованы к числовому типу; пустые значения `TotalCharges` оставлены для последующей обработки.
5. Построен график распределения целевого класса `Churn`.
6. Построено распределение ежемесячных платежей `MonthlyCharges`.

## Как читать графики

График `Распределение Churn` показывает, сколько клиентов осталось и сколько ушло. Классы распределены неравномерно: оставшихся клиентов больше. Поэтому одной только accuracy в следующих работах будет недостаточно — нужно смотреть precision, recall, F1 и ROC-AUC.

График `Распределение MonthlyCharges` показывает диапазон ежемесячных платежей. Большинство клиентов находится в среднем диапазоне, но есть и дорогие тарифы. Это может быть полезно для анализа риска оттока и сегментации клиентов.

## Вывод

Первичный анализ подтвердил, что данные подходят для построения модели оттока, но требуют подготовки: обработки `TotalCharges`, кодирования категориальных признаков и проверки дисбаланса классов. Полученные графики сохранены в notebook `practice_1.ipynb` и видны в его предпросмотре на GitHub.

## Запуск

Откройте `practice_1.ipynb`, установите зависимости из `requirements.txt` и выполните все ячейки. CSV находится в папке `data`.
