# Результаты практических работ

Репозиторий содержит семь практик по одному датасету IBM Telco Customer Churn.

| Практика | Основной результат |
|---|---|
| 1 | Первичный анализ таблицы, пропуски, баланс классов и первые графики |
| 2 | EDA: распределения, выбросы и корреляции |
| 3 | Pipeline подготовки числовых и категориальных признаков |
| 4 | Ridge-регрессия для прогноза общей суммы платежей |
| 5 | Логистическая классификация оттока и анализ стоимости ошибок |
| 6 | TF-IDF-представление профиля услуг и классификация |
| 7 | Random Forest и анализ важности признаков |

Графики, таблицы и метрики находятся внутри соответствующих notebooks. Для пояснения результата откройте README в папке нужной практики.
