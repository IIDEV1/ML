## Данные

Во всех практических работах используется один датасет `Telco-Customer-Churn.csv` из IBM Telco Customer Churn. Он содержит 7043 записи о клиентах и 21 признак: срок обслуживания, платежи, тип договора, подключённые услуги и способ оплаты.

Целевая переменная `Churn` показывает, ушёл ли клиент. Один общий датасет позволяет последовательно сравнить результаты анализа, подготовки данных, регрессии и классификации.

## Структура каждой работы

Каждая папка содержит:

- `README.md` — отчёт с целью, этапами, интерпретацией графиков и выводом;
- `practice_N.ipynb` — notebook с кодом, таблицами, метриками и графиками;
- `data/Telco-Customer-Churn.csv` — исходные данные;
- `requirements.txt` — зависимости для запуска.

## Что показывают результаты

В notebook №1 показаны структура таблицы, пропуски, баланс классов и базовые распределения.

В notebook №2 выполнен EDA: распределения, выбросы и корреляционная матрица.

В notebook №3 подготовлен воспроизводимый pipeline с заполнением пропусков, масштабированием и кодированием категорий.

В notebook №4 обучена Ridge-модель для прогноза `TotalCharges`, рассчитаны MAE, RMSE и R².

В notebook №5 построен классификатор оттока с precision, recall, F1, ROC-AUC, ROC-кривой и матрицей ошибок.

В notebook №6 сервисный профиль клиента преобразован в TF-IDF-признаки и проверен текстовый классификатор.

В notebook №7 обучен Random Forest, добавлены матрица ошибок и график важности признаков.

Все графики и основные результаты встроены в notebooks, поэтому их можно увидеть в режиме Preview на GitHub.

## Запуск

Требуется Python 3.9+ и библиотеки из `requirements.txt`.

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate
pip install -r practice-1/requirements.txt
jupyter lab
```

Откройте нужный notebook и выберите **Restart & Run All**. Для повторяемости в моделях используется фиксированное разбиение `random_state=42`.
