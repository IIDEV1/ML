Уровень B. Откройте `practice_5.ipynb`, установите зависимости из `requirements.txt` и выполните Run All.

## Описание результата

Во всех работах используется IBM Telco Customer Churn: 7043 клиентов и 21 признаков. Целевая переменная `Churn` показывает, ушёл ли клиент. В данных есть пропуски в `TotalCharges` и дисбаланс классов, поэтому графики и метрики нужно интерпретировать с учётом этих особенностей.

### Классификация

Логистическая регрессия предсказывает уход клиента. Precision, recall, F1 и ROC-AUC важнее одной accuracy из-за дисбаланса. Вывод: recall класса Churn=Yes показывает, сколько ушедших клиентов найдено.

Откройте `practice_5.ipynb` и выполните **Run All**: график и таблица результата находятся внутри notebook.
